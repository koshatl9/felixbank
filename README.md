# 🏦 FelixBank
<img width="1536" height="1024" alt="image" src="https://github.com/user-attachments/assets/7f6a4e34-014f-4086-8958-7546ac6886af" />

Современное банковское веб-приложение, разработанное с использованием **Python, Flask, React, MySQL и Docker**.

---

## 🚀 Возможности

- 🔐 Регистрация и авторизация пользователей
- 👤 Личный кабинет пользователя
- 💳 Управление банковскими картами
- 💸 Переводы между пользователями
- 📜 История операций
- 🎯 Система целей накопления
- 🔄 Автоматические переводы на цели
- 💱 Курсы валют
- 🔒 JWT-аутентификация
- ⚡ SPA без перезагрузки страниц
- 🐳 Полный запуск через Docker

---

## 🛠️ Стек технологий

| Backend | Frontend | Database | Other |
|---------|----------|----------|-------|
| Python | React | MySQL | Docker |
| Flask | Redux Toolkit | SQLAlchemy | JWT |
